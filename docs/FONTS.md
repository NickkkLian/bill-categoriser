# Self-hosted fonts

- Manrope, variable weight. Supplied local Fontsource Latin subset. SIL OFL 1.1 in `fonts/manrope-OFL.txt`. Original source https://github.com/google/fonts.
- Geist Mono, regular and bold. Supplied licensed local collection, converted to WOFF2 with fontTools with unchanged outlines. SIL OFL 1.1 in `fonts/GeistMono-OFL.txt`.

No network downloads. Two static weights or a variable weight axis are included.
